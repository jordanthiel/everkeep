# Everkeep website

Marketing landing page for Everkeep — product overview and desktop downloads.

## Develop

```bash
cd website
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Download links

Set release artifact URLs in `.env` (see `.env.example`):

- `VITE_DOWNLOAD_MAC`
- `VITE_DOWNLOAD_WIN`
- `VITE_RELEASES_URL`
- `VITE_APP_VERSION`
